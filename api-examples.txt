================================================================================
                    ONLINE RETAIL MICROSERVICES API EXAMPLES
================================================================================

Microservice Base URLs:
  - Customer Service:     http://localhost:8081
  - Product Service:      http://localhost:8082
  - Order Service:        http://localhost:8083
  - Notification Service: http://localhost:8084

================================================================================
 1. CUSTOMER SERVICE (Port 8081)
================================================================================

--------------------------------------------------------------------------------
1.1 Create Customer (Feature C1)
--------------------------------------------------------------------------------
POST http://localhost:8081/customer
Content-Type: application/json

cURL:
curl -X POST http://localhost:8081/customer \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "email": "john.doe@example.com",
    "phone": "0412345678",
    "contactMethod": "Email",
    "address": {
      "unitNumber": 12,
      "streetNumber": 100,
      "street": "George St",
      "suburb": "Sydney CBD",
      "city": "Sydney",
      "postcode": 2000,
      "state": "NSW",
      "country": "Australia"
    }
  }'

PowerShell:
Invoke-RestMethod -Uri "http://localhost:8081/customer" -Method POST -ContentType "application/json" -Body '{"name":"John Doe","email":"john.doe@example.com","phone":"0412345678","contactMethod":"Email","address":{"unitNumber":12,"streetNumber":100,"street":"George St","suburb":"Sydney CBD","city":"Sydney","postcode":2000,"state":"NSW","country":"Australia"}}'
